# R0.6.4 verification

This release is a complete runtime restore, not a narrow patch.

Verified before packaging:

- `app/page.tsx` exists (the `/` route).
- `app/layout.tsx` exists (App Router root layout).
- `/auth`, `/discover`, `/request/new`, `/admin`, `/api/health` critical route files exist.
- 15 critical runtime files checked by `scripts/preflight.mjs`.
- 72 application source files checked.
- All local `@/` imports resolve to files in the package.
- TypeScript/TSX parse check: 72 files, 0 syntax errors.
- Runtime scan contains no Mina / Ivy / MORI demo-provider fallback records.
- `.gitignore` excludes `node_modules`, `.next`, `.env*`, `*.tsbuildinfo`, and Vercel local metadata.
- Dependency versions are pinned for reproducible Vercel installs. Next.js is pinned to 15.5.23, matching the successful Vercel toolchain observed during deployment.

The package also adds an npm `prebuild` check. Every future `npm run build` / Vercel build will first verify that the root page, root layout, critical routes, and local imports have not gone missing.

No Neon migration is required when moving from R0.6.3 to R0.6.4.
