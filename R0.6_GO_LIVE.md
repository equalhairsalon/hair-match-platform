# R0.6 Beauty Platform + Super Admin — Go Live

Base: current R0.5.1 STRICT LIVE DATA.

## 1. Update source
Unzip the R0.6 PATCH and copy the CONTENTS of the patch folder over your existing `hair-match-platform` project.
Do not copy `node_modules`, `.next` or `tsconfig.tsbuildinfo`.

## 2. Neon migration
In Neon → Query, run:

`database/R0.6_MIGRATION.sql`

It is written to be safe to run repeatedly.

## 3. Create your Super Admin once
First register an account normally on the site. Then run in Neon (replace the email):

```sql
update users
set role='admin', account_status='active', updated_at=now()
where lower(email)=lower('YOUR_EMAIL');

insert into platform_admins(user_id,admin_level,permissions,is_active)
select id,'super_admin','{"all":true}'::jsonb,true
from users
where lower(email)=lower('YOUR_EMAIL')
on conflict(user_id) do update
set admin_level='super_admin',permissions='{"all":true}'::jsonb,is_active=true,updated_at=now();
```

Log out and log back in so the JWT session receives the admin role.

Super Admin URL: `/admin`

## 4. Deploy
```bash
git add -A
git commit -m "R0.6 beauty platform super admin"
git push origin main
```

Vercel redeploys automatically.

- `/admin/billing`
